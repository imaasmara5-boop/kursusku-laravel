KONSEP YANG DIPAHAMI SETELAH MENGGUNAKAN AI
=========================================================

1. Route Model Binding
   Laravel otomatis mencari model Course berdasarkan ID di URL
   (misal /courses/5 → $course = Course::find(5)) dan
   menyuntikkannya ke parameter method controller.

2. Form Request sebagai "Satpam"
   StoreCourseRequest dan UpdateCourseRequest adalah tempat
   khusus untuk authorization dan validation rules.
   Controller menjadi bersih karena tidak lagi berisi
   aturan validasi.

3. validated()
   Mengambil hanya data yang lolos rules dari Form Request,
   lebih aman daripada $request->all().

4. Rule::unique()->ignore($course)
   Saat update, code milik record yang sedang diedit harus
   diabaikan agar tidak dianggap duplicate. Tanpa ignore(),
   edit tanpa mengubah code akan gagal dengan error
   "The code has already been taken".

5. old('field', $currentValue)
   Menjaga input terakhir user saat validasi gagal,
   agar user tidak perlu mengetik ulang seluruh form.

6. @method('PUT') dan @method('DELETE')
   Method spoofing karena HTML form hanya mendukung GET
   dan POST. Laravel menerjemahkan @method('PUT') menjadi
   route PUT courses/{course} dan @method('DELETE') menjadi
   route DELETE courses/{course}.

7. @csrf
   Token CSRF wajib ada di setiap form POST/PUT/DELETE
   untuk mencegah cross-site request forgery.

8. Feedback error dekat field
   Pola @error('field') <div class="error-message">
   {{ $message }}</div> @enderror ditempatkan tepat
   setelah input, bukan hanya di atas form.
