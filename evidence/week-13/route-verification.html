Source-Level Verification: Course Index

Proyek KursusKu telah diperbarui untuk Pertemuan 13. Fitur data discovery (Search, Filter, Pagination) telah diimplementasikan pada CourseController dan view courses.index dengan tema ungu. Source check berikut memverifikasi struktur kode sebelum pengujian 5 skenario wajib:

PASS | CourseController@index menerima Illuminate\Http\Request
PASS | Query builder menggunakan when() untuk search parameter 'q'
PASS | Query builder memvalidasi filter 'status' (open/closed/draft)
PASS | Pagination diatur paginate(10)->withQueryString()
PASS | courses/index.blade.php menggunakan @forelse untuk empty state
PASS | Form search menggunakan method="GET" (progressive enhancement)
PASS | CSS kustom tema ungu diterapkan pada form dan pagination
PASS | Database memiliki minimal 21 course dummy dengan variasi status

Setelah verifikasi source, jalankan 5 skenario pengujian wajib (0 hasil, 1 hasil, >10 hasil, keyword spasi, filter + page 2) dan bekukan screenshot ke folder evidence/week-13/ untuk penyusunan draft artikel ilmiah sesuai panduan halaman 18.
